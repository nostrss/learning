# 사전 지식: 3년 차 TS 프론트엔드, Rust 툴체인 설치 완료

jintagi는 JS/TS에 능숙한 3년 차 프론트엔드 개발자다. 변수·함수·비동기·모듈·npm·HTTP·JSON은 다시 가르치지 않는다. 백엔드 경험은 없다고 가정한다. rustc/cargo 1.95.0이 macOS에 설치되어 있다(2026-10-10 스크린샷으로 확인).

## Implications
- 모든 Rust 개념은 TS 대응물에서 출발한다(참조 공유 → move, union → enum, interface → trait, Promise → Future).
- 주 5시간. 출퇴근 모바일 학습을 원하므로 각 레슨마다 채널에 마크다운 요약을 함께 올린다(NOTES.md 참고).
- Lesson 1(ownership/move)부터 시작. 아직 이해 증거는 없음 — 과제 제출 후 별도 기록.
