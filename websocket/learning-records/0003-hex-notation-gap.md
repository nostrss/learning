# 16진수(0x) 표기가 사전 지식이 아니었음 — 레슨 2에서 보충함

레슨 2의 opcode 표를 읽다가 "0x2, 0x8은 뭐야? 이 표기 읽는 법을 알려줘"라고 질문함. 16진수 표기와 "한 자리 = 4비트" 대응이 사전 지식이 아니었고, 대화에서 보충 설명함 (용어집 [[glossary]]에 0x 표기 항목 추가).

**Implications** — 프론트엔드 경력자라도 비트/진법 기반 지식을 전제하면 안 됨. 이후 레슨(close code 숫자, 바이트 다이어그램 등)에서 새 수 표기가 나오면 첫 등장 시 한 줄 설명을 붙일 것. 반대로 질문 후 이해는 빨랐으므로(4비트 대응까지 연결) 한 번 설명하면 충분함.
