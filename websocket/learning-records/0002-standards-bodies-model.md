# 표준화 기구의 계층 분업 모델을 이해하고 새 사례에 적용함

"웹표준이 두 개인가?"라는 혼란에서 출발해, IETF(와이어 프로토콜/RFC)와 WHATWG(브라우저 API/Living Standard)의 분업·참조 관계를 이해함. 이후 확인 질문에서 fetch() → WHATWG, HTTP → IETF를 스스로 올바르게 짝지음 — 배운 구도를 WebSocket 밖의 사례로 전이한 증거.

**Evidence** — "fetch()는 WHATWG, HTTP는 IETF 맞아?"라고 먼저 답을 제시함 (2026-07-26).

**Implications** — 레슨 1의 핵심 개념(핸드셰이크 + 이중 표준 구조)이 소화됨. 다음 레슨은 커리큘럼 ②번 프레임 구조(opcode/마스킹)로 진행 가능. 스펙 문서를 인용할 때 "이건 WHATWG 쪽/IETF 쪽" 프레이밍이 잘 통함.
