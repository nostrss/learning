# Lesson 1 완료, Copy의 "왜"는 아직 70%

2026-10-11 jintagi가 Lesson 1 완료를 알림(과제 코드는 repo에 없음, 로컬 진행으로 보임). 그 과정에서 `Copy`가 무엇인지, `i32`가 이름인지 타입인지, "비트 그대로 복제"가 왜 위험할 수 있는지 연달아 질문. 스택 바이트/힙 포인터 그림 설명 후에도 "완전히 이해는 안 간다"고 함. 최소 기준(move vs Copy 구분 + 컴파일러 에러 읽기)만 잡고 진행하기로 함.

## Implications
- 메모리 그림(스택 바이트 vs 힙 포인터)이 아직 낯설다. Lesson 2에서 참조 그림으로 같은 모델을 한 번 더 보여줌(spacing).
- 튜플 Copy 퀴즈는 답하지 않음 → Lesson 2 첫머리 복습 문제로 배치.
- 타입 표기(`: i32`) 같은 기초 문법도 걸릴 수 있음. 레슨 코드에 새 문법이 나오면 한 줄 설명을 붙인다.
