6.042J · Lesson 0004 · Lecture 1 · 교재 §1.3술어와 한정사: ∀와 ∃

레슨 1에서 "x + 1 = 3"은 명제가 아니라고 했다 — x에 따라 진위가 달라지니까. 오늘 그 문장에 이름을 붙인다: 술어(predicate). 그리고 술어를 명제로 바꾸는 두 개의 장치, ∀(for all)와 ∃(there exists)를 배운다. 수학 문장의 뼈대가 이 둘이다.

미션 연결. 술어는 boolean을 반환하는 함수, ∀는 every(), ∃는 some()이다. 알고리즘 책의 "for all n ≥ n₀, f(n) ≤ c·g(n)" 같은 문장(빅오의 정의다)을 읽으려면 이 기호들이 자동으로 해석돼야 한다. 오늘이 그 자동화의 시작.

1. 술어(predicate)

술어란 변수 값에 따라 진위가 결정되는 명제다. 함수처럼 이름 붙여 쓴다:

P(n) ::= "n is a perfect square"

P(4)는 참(4 = 2²), P(5)는 거짓. (기호 ::=는 "정의상 같음"이다.) 코드로는 정확히 이것:

const isPerfectSquare = (n) => Number.isInteger(Math.sqrt(n));

주의 하나: 술어 P(n)은 진위값을 내고, 보통 함수 p(n) = n² + n은 수치값을 낸다. 표기가 닮아서 헷갈리기 쉽다 — 교재도 "Don't confuse these two!"라고 굵게 경고한다.

2. 두 개의 한정사(quantifier)

술어에 대해 흔히 하는 주장은 두 가지다: 항상 참이다, 어떤 값에서는 참이다.

기호읽기뜻코드 대응
∀x ∈ D. P(x)for all — 모든 x에 대해universally quantifieddomain.every(p)
∃x ∈ D. P(x)there exists — 어떤 x가 존재existentially quantifieddomain.some(p)

∀는 뒤집힌 A(All), ∃는 뒤집힌 E(Exists). ∈는 "…의 원소"이고, ℕ은 음이 아닌 정수 {0, 1, 2, …}, ℤ는 정수 전체, ℝ은 실수다. 레슨 1의 소수 명제를 이 표기로 다시 쓰면:

∀n ∈ ℕ. p(n) is prime        (거짓이었다 — n = 40이 반례)

3. 한정사의 순서가 뜻을 바꾼다

교재의 예: "Every American has a dream." 애매한 문장이다. H(a, d) = "미국인 a는 꿈 d를 가진다"로 놓으면 두 해석이 갈라진다:

수식뜻
∃d. ∀a. H(a, d)모두가 공유하는 단 하나의 꿈이 존재한다
∀a. ∃d. H(a, d)각자 자기만의 꿈이 있다 (사람마다 달라도 됨)

Goldbach 추측으로도 확인: ∀n ∈ Evens. ∃p, q ∈ Primes. n = p + q ("모든 짝수는 어떤 두 소수의 합")는 미해결 추측이지만, 순서를 바꾼 ∃p, q. ∀n. n = p + q ("모든 짝수가 같은 두 소수의 합")는 명백히 거짓이다.

개발자 번역. 중첩 루프의 순서와 같다. ∀a. ∃d는 "각 a마다 안쪽에서 자기 d를 찾으면 됨"(a마다 달라도 OK), ∃d. ∀a는 "바깥에서 d 하나를 고정한 뒤 모든 a를 통과해야 함". 바깥 변수는 안쪽에 의존할 수 없다 — 클로저 변수 캡처 순서와 같은 감각이다.

4. 한정사의 부정 — NOT을 통과시키면 종류가 바뀐다

NOT(∀x. P(x)) is equivalent to ∃x. NOT(P(x)). — Mathematics for Computer Science, §1.3.8 · 번역: "모두 P다"의 부정은 "P가 아닌 것이 존재한다"이다.

"모두가 스노보드를 좋아하는 건 아니다" = "스노보드를 안 좋아하는 사람이 존재한다". 대칭으로 NOT(∃x. P(x)) IFF ∀x. NOT(P(x))도 성립한다. 일반 원리: NOT이 한정사를 넘어갈 때마다 ∀↔∃가 뒤바뀐다.

!arr.every(p)  ===  arr.some(x => !p(x))
!arr.some(p)   ===  arr.every(x => !p(x))

이게 레슨 1의 반례(counterexample)가 작동하는 원리다: ∀ 주장을 무너뜨리는 데 반례 하나의 존재(∃)면 충분한 이유가 이 동치에 들어 있다.
