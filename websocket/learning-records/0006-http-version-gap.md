# HTTP 버전(1.1/2/3) 구분이 사전 지식이 아니었음 — 배경 절로 보강

레슨 5(HTTP/2·3 위의 WebSocket)를 받고 "HTTP 1.1/2/3의 차이를 모른다"고 직접 밝힘. 레슨이 버전 차이를 전제로 쓰여 있었던 것 — [[0003-hex-notation-gap]]과 같은 계열의 사전 지식 공백. "의미론은 동일, 전송 방식만 다름 → 한 번에 하나(1.1) / 한 연결에 스트림 멀티플렉싱(2) / UDP+QUIC(3)" 표와 ALPN 자동 협상, 실제 사용 분포(h2 ~80%, h3 ~30%, WebSocket은 여전히 대부분 1.1 Upgrade)를 배경 절로 본문에 추가함.

**Evidence** — 사용자가 공백을 스스로 밝히고 "일반적으로 쓰는 환경"을 질문 (2026-07-26).

**Implications** — HTTP 계층 자체(버전, 협상, 프록시)는 앞으로도 전제하지 말 것. 레슨 6(permessage-deflate)에서 압축(gzip/deflate) 개념도 사전 확인 필요할 수 있음. 공백을 스스로 밝히는 학습 태도가 자리 잡음 — 질문 유도가 잘 작동하고 있다.
