# Notes

- 사용자: 프론트엔드 개발자, 브라우저 WebSocket API 직접 사용, 재연결/상태관리 래퍼 자체 구현 경험
- 학습 깊이: RFC 수준 원함 (스펙 원문을 읽을 수 있는 수준이 목표)
- 언어: 한국어로 티칭, 기술 용어는 원어 유지
- 커리큘럼: ① 핸드셰이크(완료, 이해 확인됨) → ② 프레임 구조(완료, 질문 다수로 보강됨) → ③ 종료 핸드셰이크와 close code(완료, 질문 4건으로 보강됨) → ④ ping/pong과 keepalive(완료, 질문 2건으로 보강됨) → ⑤ HTTP/2·3 위의 WebSocket(완료, 질문 3건으로 보강됨) → ⑥ 확장 permessage-deflate(레슨 작성됨) — 계획된 6강 전체 작성 완료, 다음은 예약된 실습
- 실습 예약: 라이브러리 없이 Node http 모듈로 최소 WebSocket 서버 만들기 (레슨 ② 소화 후)
- 커뮤니티 가입 선호 미확인
- 네트워크 기초(16진수 표기, TLS/계층 개념, HTTP 버전 1.1/2/3 구분)는 사전 지식으로 전제하지 말 것 — 질문 후 흡수는 빠름. "TCP → TLS → HTTP/WebSocket 계층 그림"이 잘 통했으니 새 개념은 이 그림에 위치시켜 설명하기
- 한자 번역어("단편화")보다 프론트엔드 실무 용어(청크, 스트리밍, fetch)로 매핑해 설명하면 잘 통함 — 새 용어 도입 시 실무 대응물부터 제시할 것
- 새 개념(알고리즘류)은 정의보다 장난감 예시를 먼저 — 레슨 6이 어렵다는 피드백(2026-08-02)으로 LZ77 손풀이·통화 비유·공격 시나리오를 추가하니 해소. 개념 밀도가 높은 레슨은 "예시 → 정의 → 표" 순서로 쓸 것
